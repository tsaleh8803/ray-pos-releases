# Ray POS — Releases

Public download + auto-update feed for **Ray POS**, the in-shop point-of-sale
app for Ray Barber Shop (Broumana).

The application source lives in a separate private repository. This repo only
hosts the published Windows installers and the `latest.yml` update manifest, so
installed copies can auto-update without needing any access token.

## Install / update

Download the latest `Ray POS-x.y.z-Setup.exe` from the
[**Releases**](https://github.com/tsaleh8803/ray-pos-releases/releases) page and
run it. Once installed, the app checks this feed and updates itself automatically.

> Requires the Microsoft Visual C++ 2015–2022 x64 runtime
> ([vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)) on first install.
